# 🍅 Pomodoro Timer

A simple and cute Pomodoro timer built with Python and Tkinter!

This app helps you stay focused using the Pomodoro Technique — 25 minutes of work followed by short breaks. It's perfect for studying, working, or deep coding sessions 🧠💻

---

## ✨ Features

- 25-minute work sessions
- 5-minute short breaks
- 20-minute long breaks after 4 sessions
- Tomato-themed UI because... why not? 🍅
- Built with love using Tkinter 💛
